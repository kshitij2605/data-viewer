Two-Phase AI Strategy Advisor

単一プロンプトでは大きなテーブルを見落とし汎用的な助言に。64kコンテキストを活用した2段階パイプラインで解決。A single-prompt approach failed — the LLM missed large tables and produced generic advice. We solved this with a two-phase pipeline using the full 64k context window.

📐

フェーズ1：ドキュメント分析Phase 1 — Document Analysis

全マークダウンをLLMに送信（大文書は約5万文字ずつ並列分析）。セクション名・文字数・テーブルサイズ・構造パターンを正確に計測。The full markdown is sent to the LLM (split into ~50k char parts for large docs, analyzed in parallel). The model measures exact section names, character counts, table dimensions, and structural patterns — no guessing.

🎯

フェーズ2：戦略推奨Phase 2 — Strategy Recommendation

分析結果を基に第2プロンプトで戦略を推奨。実際のセクション名と計測サイズを引用し、汎用的な助言は明示的に禁止。Analysis results feed a second prompt that generates strategy recommendations — citing actual section names and measured sizes. Generic advice is explicitly forbidden.

Scoring Limitations

RAGおよびFAQ有用性スコアは方向性の指標として有用ですが、権威ある指標とするには2つの課題が残っています。The RAG and FAQ usefulness scores are useful directional signals, but two gaps remain before they can be treated as authoritative.

⚠️

キャリブレーション例なしNo Calibration Examples

現在のプロンプトにはスコア付きチャンク例（Few-shot）がありません。スコア帯ごとに2〜3個のアンカー例を追加すれば一貫性が向上し、文書種別間のスコアのばらつきを抑制できます。The current prompt contains no scored example chunks (few-shot). Adding 2–3 anchor examples per score band would tighten consistency and reduce score drift across different document types.

⚠️

人間による検証基準なしNo Human Validation Baseline

スコアはCohen's Kappaなどの評価者間一致度指標を用いた人間のアノテーションとの照合がまだ行われていません。スコアを権威あるものとするにはこの校正が必要です。Scores have not been validated against human annotations using inter-rater agreement metrics such as Cohen's Kappa. This calibration step is needed before scores can be considered authoritative.

Cohen's Kappa

2人の評価者が偶然を超えてどの程度一致するかを測る統計的信頼性指標。A statistical measure of inter-rater reliability — how much two raters agree beyond what chance alone would predict.

計算式The Formula

κ = (Po − Pe) / (1 − Pe)
  • ▹ Po観測一致率（実際の一致頻度） = observed agreement (how often raters actually agree)
  • ▹ Pe期待一致率（偶然による一致） = expected agreement (chance-level agreement)
  • ▹ κ = 1 → perfect agreement   κ = 0κ=1で完全一致、κ=0は偶然のみ → chance only

なぜ必要かWhy We Need It

  • ▹LLMスコアは1評価者 — 比較用の人間評価者が必要 Our LLM scores are one "rater" — we need a human rater to compare against
  • ▹単純一致率は誤解を招く — 偏ったデータでは偶然で80%一致も Raw agreement % is misleading — two raters could agree 80% by chance on skewed data
  • ▹Kappaは偶然を補正 — κ≥0.6で実質的な一致 Kappa corrects for chance — κ ≥ 0.6 indicates substantial agreement
  • ▹本番利用前にLLM評価スコアの信頼性を検証 Validates whether LLM-as-a-Judge scores are trustworthy before production use
κ < 0  Poor 0.0–0.2  Slight 0.2–0.4  Fair 0.4–0.6  Moderate 0.6–0.8  Substantial 0.8–1.0  Almost Perfect
